## 📖 项目简介

**PoseStudio** 是一个轻量级、免安装、基于现代 Web 技术的 3D 摄影人像姿态与线条生成工具。

本工具深度融合了知名摄影教学系列 **Fotobeginner（摄影入门）** 的全套经典 21 人像姿势精粹，收录 **101 张大师手绘原稿** 与 **36 款高精度 3D 交互姿态**（涵盖女生、男生、儿童与情侣）。它既能作为摄影师在日常实拍中指导模特摆姿的速查手册，也是 AI 绘画（Stable Diffusion、ComfyUI、WebUI、Flux、Midjourney）创作者导出精准 **ControlNet OpenPose 彩色骨骼图** 与 **Lineart 手绘线稿参考图** 的高效利器。

## 🌟 核心功能亮点

### 1. 🦴 3D 自由交互骨骼与双人情侣系统
- **36 款精编摄影姿态**：覆盖各种常用站姿、坐姿、靠姿、卧姿、情绪大片与情侣互动。
- **双人人像实体系统**：原生支持 `personA`（主模特）与 `personB`（副模特/伴侣）独立骨架计算，支持情侣深情相拥、牵手漫步、公主抱等复杂交互。
- **正向运动学（FK）微调**：点击 3D 视口中的任意彩色关节点，即可在右侧面板通过 X / Y / Z 滑块微调关节位置，微调后支持一键保存为个人自定义姿势（持久化存储于本地 LocalStorage）。
- **一键姿态还原**：点击导航栏 `↺ 还原姿态`，随时复位当前姿态至官方标准角度。

### 2. 🎨 101 张 Fotobeginner 大师手绘线稿图库 (Lineart Gallery)
- **无损收录 101 张手绘原稿**：完整收录女生篇(I&II)、男生篇、儿童篇、情侣篇五大专题原画。
- **沉浸式大图画廊预览 (Lightbox)**：点击任意卡片缩略图或标题，立刻弹出暗房磨砂质感的高清大图窗口，白色画纸底板凸显细腻铅笔素描线条。
- **便捷翻页与快捷键**：
  - 点击悬浮切换箭头 `‹` / `›`，或使用键盘 **`←` / `→`** 左右方向键循环浏览当前专题。
  - 按下键盘 **`ESC`** 键（或点击黑色遮罩、右上角 ✕ 按钮）快速秒退。
- **一键本地下载 (PNG)**：弹窗与列表均配有直接下载按钮，采用安全的 Blob 本地数据流，直接唤起浏览器保存（规范命名如 `Fotobeginner_女生篇(I)_回眸微笑.png`）。

### 3. 🧍 立体人体轮廓透视（Silhouette System）
- **解剖胶囊体与体块系统**：内置胸腔、骨盆、头颅立体网格与四肢 12 段锥度胶囊体，清晰呈现身体体块朝向、重力分布与近大远小的透视压缩感。
- **轮廓透明度自由调节**：可无级调节人体轮廓的可见性与透明度（0% ~ 100%）。

### 4. 📷 真实摄影机位与画幅取景框
- **经典定焦焦段**：28mm（广角街拍环境人像）、50mm（标准人文透视）、85mm（黄金空气切割人像）。
- **人像黄金画幅**：3:4（经典杂志人像）、9:16（移动端全屏壁纸）、1:1（方形画幅 / Flux 推荐）、2:3（胶片全画幅高分）。
- **多机位预设**：正面平视、左侧 45°、右侧 45°、仰角大长腿、微俯角情绪构图一键切换。

### 5. 🤖 ControlNet 多通道专业导出引擎
采用离屏高保真渲染器，输出绝对纯净、无杂色的参考垫图：
- **`手绘线稿: 纯白底黑线`**：Lineart / Sketch 推荐，精准黑白二值轮廓线。
- **`手绘线稿: 纯黑底白线`**：Canny / Softedge 专用高对比边缘线。
- **`标准 OpenPose 彩色骨骼`**：严格遵循 ControlNet 18 节点色彩标准，黑底输出。
- **`骨骼 + 人体轮廓复合图`**：带半透明体块，适合作为垫图（Img2Img）的透视空间参考。
- **`纯人体剪影轮廓图`**：白色 Mask 蒙版，方便提取遮罩与抠图。
- **多阶主流分辨率导出**：768×1024、896×1152、1024×1024、720×1280、1024×1536，并支持透明背景 PNG。

## 🚀 快速启动指南

本项目为纯前端原生架构，无需安装 Node.js、npm 等复杂环境，**开箱即用**。

### 方式 A：Windows 一键快速启动（推荐）
在项目根目录下，直接双击运行：
```cmd
启动姿势库.bat
```
脚本将自动启动本地极速 HTTP 服务并打开默认浏览器：`http://localhost:8080/index.html`。

### 方式 B：Python 命令行启动
打开终端，在项目根目录运行：
```bash
python -m http.server 8080
```
然后在浏览器访问 `http://localhost:8080/index.html` 即可。

### 方式 C：IDE 插件（VS Code Live Server）
在 VS Code 中右键点击 `index.html`，选择 **"Open with Live Server"** 即可。

### 方式 D：☁️ 静态托管平台一键部署（Netlify / Vercel / Cloudflare Pages）
本项目已内置完整的 [`netlify.toml`](./netlify.toml) 与 [`_headers`](./_headers) 配置文件，全站纯静态，零构建指令：
- **Netlify 部署**：
  1. 将本项目代码推送到 GitHub / GitLab / Bitbucket，或直接拖拽整个项目文件夹到 [Netlify Drop](https://app.netlify.com/drop)。
  2. **Build command**：留空（无需编译构建）
  3. **Publish directory**：填 `.` 或留空（即根目录）
  4. 点击 **Deploy Site**，数十秒内即可获得可全球 CDN 访问的专属独立域名！
- **Vercel / Cloudflare Pages**：直接导入仓库，Root Directory 选择当前根目录，直接 Deploy 即可。

## 🤖 ControlNet & AI 绘画实战工作流

### 1. Stable Diffusion WebUI 实战配比
- **骨骼模式 (OpenPose)**：
  - 在 PoseStudio 中选择所需姿势，点击 `⬇️ 下载姿态参考图`（导出模式选择：**标准 OpenPose 彩色骨骼**）。
  - 将生成的 PNG 拖入 WebUI ControlNet 单元。
  - **Preprocessor（预处理器）**：选择 `none`（因为导出的已经是标准 OpenPose 图，无需重复提取）。
  - **Model（模型）**：选择 `control_v11p_sd15_openpose` 或 `control_lora_rank128_v11p_sd15_openpose`（SDXL 请选择对应 SDXL OpenPose 模型）。
  - **Weight（权重）**：建议 `0.85 ~ 1.0`。
- **线稿模式 (Lineart / Sketch)**：
  - 在 PoseStudio 手绘图库中直接下载线稿原画，或在 3D 模式导出 **白底黑线**。
  - 将 PNG 拖入 ControlNet 单元，Preprocessor 选择 `none`，Model 选择 `control_v11p_sd15_lineart` 或 `control_v11p_sd15_scribble`。

### 2. ComfyUI 工作流节点连接
```
[Load Image] (PoseStudio 导出的 OpenPose / Lineart PNG)
      │
      ▼
[Apply ControlNet] ◄── [ControlNet Loader] (选择 openpose 或 lineart 权重模型)
      │
      ▼
[K播种器 / KSampler] ──► [VAE Decode] ──► [Save Image]
```

### 3. SDXL / Flux 黄金分辨率推荐表
- **经典人像比例**：`768 × 1024`（3:4，最不易出现多头多肢畸形）
- **超清质感比例**：`896 × 1152`（SDXL 原生黄金分辨率）
- **胶片全身大片**：`1024 × 1536`（2:3 胶片全画幅高分）
- **社交媒体壁纸**：`720 × 1280`（9:16 移动端竖屏）
